# software-process 软件过程项目
## 项目介绍
软件工程课程项目，基于SpringBoot后端开发。

## 技术栈
- 后端：SpringBoot + MyBatis
- 数据库：MySQL
- 版本管理：Git/GitHub

## 环境配置
1. JDK 1.8+
2. Maven 3.6+
3. MySQL 8.0

## 项目结构
- src/：后端源代码
- docs/：需求、设计、测试文档
- sql/：数据库建表脚本

## 启动方式
1. 导入SQL脚本到MySQL
2. 修改本地数据库配置
3. 启动SpringBoot主类
