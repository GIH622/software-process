# CR-2026-1020-001：续借候选实现及现状

团队《6-需求变更及影响分析.docx》已列明：**续借一次延长15天、最多1次、到期当天允许续借**；
数据库快照中的审批字段为“批准”，但实施日期、测试结果仍为空。批准 ≠ 已部署验收。

当前参考实现 `BorrowService.renew()` 已存在；端点为：
`POST /api/borrow_records/{id}/renew`，需要登录 Cookie 和 `X-CSRF-Token`。
`LIBRARY_RENEWAL_ENABLED=false` 时，当前接口返回 `409 RENEWAL_DISABLED`（不是 404）。
执行可选 `sql/20_CR001_renewal_optional.sql` 的数据库迁移并经过 QA 验证后，才能按团队决议启用。

功能约束：本人或管理员、记录未归还、尚未逾期、读者没有其他逾期记录、最多1次；
成功后 `expected_return_date += 15天`、`renew_count += 1`，副本库存不变化。
SQL 要先备份并查询是否存在 `renew_count`，**不要在现有库上重复执行 ALTER**。
