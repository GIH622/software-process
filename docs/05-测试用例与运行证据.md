# 开发测试计划与验收材料

## 测试层次
- 静态：Java17的 JDK语法解析、前端JS语法、JSON格式、SQL危险语句排查、项目结构核对。
- 自动化：`mvn clean test`，H2 + Spring Boot 测试 **38** 条（BorrowServiceIntegrationTest 21、ApiControllerTest 13、RenewalServiceIntegrationTest 4）。H2仅可验证基本业务事务/异常及HTTP约定，不代替MySQL真实锁测试。
- 手动：MySQL8增删改查、Postman全部接口、真实MySQL多线程同副本借阅争抢、重启后数据可查、管理员业务和浏览器操作。
- 变更回归：R003默认禁用，应返回409；在受控迁移和开启配置后单独执行续借成功/重复续借/逾期/越权等回归。

## 每项测试的证据清单
记录：执行时间（北京时间）、运行环境版本（JDK/Maven/MySQL）、测试步骤、请求参数（隐藏密码）、期望、实际响应、数据库对照SQL、执行人、最终 PASS/FAIL、截图或测试报告路径（例如本机 `target/surefire-reports/`）。**尚未执行的全部标记“待执行”，不得手动填成已通过。**

## MySQL一致性验收
使用`sql/04_verify_consistency.sql`四类不一致检查：读者borrowed_count对不上、在借记录与图书状态不符、图书已借但无在借记录、一本书存在多条有效借阅。要求0行。日志、回滚和10线程请真实留证。

## 注意对真实共享库进行的测试会改变数据
非只读操作必须在 `library_dev` 进行；严禁因方便测试而用队友的真实 `library_db` 重置读者密码/删除借阅记录/清空表。需要共享联调必须明确测试账号、时间和数据恢复方式。
