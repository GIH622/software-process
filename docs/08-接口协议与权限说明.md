# API 与安全约定

基础地址：`http://127.0.0.1:8080`。响应 JSON 通常为 `{ "code": 200, "message": "success", "data": ... }`；具体以 `ApiResult` 为准。

| 方法 | 路径 | 权限 | 功能/请求字段 |
|---|---|---|---|
| GET | /api/health | 公共 | HTTP存活，不代表数据库健康 |
| POST | /api/auth/login | 公共 | `{"account":"1001","password":"(本机填写)"}`；成功保存Cookie和CSRF |
| GET | /api/auth/me | 登录 | 查询角色和会话信息 |
| POST | /api/auth/logout | 登录+CSRF | 注销会话 |
| GET | /api/books?keyword=三体 | 登录 | 检索书目及当前副本状态 |
| POST | /api/borrow | 登录+CSRF | `{"barcode":"BC-0001","readerCardNo":"1001"}`，非管理员只能借自己 |
| POST | /api/return | 登录+CSRF | `{"barcode":"BC-0001"}`，非管理员只能归还自己的记录 |
| GET | /api/borrow_records/my | 读者 | 查询自己借阅历史 |
| POST | /api/borrow_records/{id}/renew | 登录+CSRF，且R003已启用 | 续借一次；默认禁用返回409 |
| POST | /api/admin/readers | 管理员+CSRF | 新增读者 |
| POST | /api/admin/books | 管理员+CSRF | 入库一本唯一条码图书 |
| POST | /api/admin/readers/{id}/freeze | 管理员+CSRF | 冻结读者 |
| POST | /api/admin/readers/{id}/unfreeze | 管理员+CSRF | 解冻并重新按未还逾期判断 |
| POST | /api/admin/readers/{id}/deactivate | 管理员+CSRF | 无借阅时注销 |
| POST | /api/admin/books/{barcode}/retire | 管理员+CSRF | 未借出时下架 |
| GET | /api/admin/readers | 管理员 | 管理台读者列表（状态、已借/上限，不含口令哈希） |
| GET | /api/admin/overdue | 管理员 | 逾期列表 |
| GET | /api/admin/logs | 管理员 | 最近日志 |
| GET | /api/admin/borrow-records/export | 管理员 | UTF-8 CSV导出 |

错误状态：401 未登录/登录失败；403权限/CSRF不足；400参数错误；404对象缺失；409业务冲突（例如无库存、重复归还、R003关闭）；500数据库或服务异常。注意它是本机教学演示，不应公网暴露，生产环境应进一步加固。

## Postman 使用提示
浏览器和 Postman 均通过 Session Cookie 保持身份；登录接口返回 `csrfToken`，后续所有非GET业务请求带 `X-CSRF-Token`。管理员登录会覆盖同一 Postman 环境的读者会话，如要继续测试读者接口需重新读者登录。
