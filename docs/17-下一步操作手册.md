## 7. 开发工程师：修 BUG-01（2 分钟）

**问题**：`scripts/check-environment.ps1` 以 UTF-8 无 BOM 存盘，中文 Windows 的 PowerShell 5.1 按 GBK 解码，引号错位导致 `ParserError: The string is missing the terminator`。

**做法**

```powershell
cd "D:\作业\大三上\软件过程实验作业\software-process"
$p = 'scripts\check-environment.ps1'
$t = [IO.File]::ReadAllText($p, [Text.UTF8Encoding]::new($false))
[IO.File]::WriteAllText($p, $t, [Text.UTF8Encoding]::new($true))
git add $p
git commit -m "fix(script): 脚本转为带BOM的UTF-8（原因：BUG-01，PowerShell 5.1 按GBK解码导致解析失败）"
```

**做完怎么确认**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\check-environment.ps1
# 应正常输出 java/javac/mvn/mysql 检出结果与 3306 连通性，无 ParserError
```

**注意**：以后所有含中文的 `.ps1` 都必须存成带 BOM 的 UTF-8；`package.json` 反过来绝对不能有 BOM。
