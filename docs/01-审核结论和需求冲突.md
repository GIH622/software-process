# 本轮最终代码审查与版本决策

> **状态更新（2026-10-23）**：本文分析的旧库 `library_db` 已退役，`password_md5`/MD5 兼容方案已按 `docs/14-里程碑-旧库退役与统一新库.md` 全面替换为 `password_hash`/纯 BCrypt。本文保留作为决策过程记录。

## 被审核的实际材料
1. 初期四人 GitHub 分工规范、成员3旧开发包。
2. `1-需求池.xlsx`、`2-需求分析报告.docx`、`3-需求规格说明 (1).docx`，作为功能/测试的主要依据。
3. `SpringBoot 后端需要连接 zlx 的 MySQL 数据库指南.docx`，含已有样例条码和证号。
4. 上一轮 73 文件开发交付包，以及本轮新上传的 43 文件 `图书借阅归还登记系统_开发交付完整版.zip`。
5. 本轮真实库导出 `library_db.sql`（2026-10-21，MySQL 8.0.44），**只是导出时刻的快照，不代表在线库永不变化**。

## 真正确定的数据库事实
实际五张表：`reader_account`、`book_inventory`、`borrow_record`、`operation_log`、`requirement_change_log`。
- reader_account 包含 `password_md5 VARCHAR(64)`，**不包含**上一轮代码所需的 `password_hash` 与 `manual_frozen`。
- operation_log 字段叫 `book_isbn`，不是上一版 `barcode`。
- borrow_record 目前没有 `renew_count`、`active_book_id` 或活动借阅唯一生成列。
- 已提供样例副本 `BC-0001`、`BC-0002`、`BC-0003` 和读者证号 `1001`、`1002`；导出时借阅记录为空。
- requirement_change_log 含 `CR-2026-1020-001 / R003`，状态“已批准”，但 `implement_date`、`verify_result` 为空，**不等于已实施或测试通过**。

## 合并改动
| 关键点 | 旧材料冲突/不足 | 最终代码选择 |
|---|---|---|
| 表与列 | v2使用额外密码/冻结/日志列；新 ZIP直接用MD5 | 适配真实字段；新用户BCrypt存旧列；旧MD5仅兼容验证、不默认改写 |
| 事务 | 新 ZIP 测试较少，异常回滚证据不足 | Spring `@Transactional` + `FOR UPDATE` + 故障注入 + H2测试 + 真MySQL检查脚本 |
| 锁与并发 | 真实库缺少活动借阅唯一约束 | 已实施应用层锁；可选生成列唯一索引须事前审查、备份后审批添加 |
| 逾期 | 新需求不计罚款、30天借期；旧代码计罚金 | 不收取罚款，只记录逾期天数并限制借阅 |
| 身份鉴权 | 新 ZIP使用管理员固定token，读者MD5登录，没完整CSRF | 采用登录会话、管理员角色、CSRF、环境变量密码；仅作可信本机教学演示 |
| 续借 | 先前需求池“待评审”；本轮SQL审批行“批准”但未实施/验证 | R003可选代码及独立迁移，默认关闭；QA通过后开启 |
| 真实证据 | 各 ZIP 有报告和模板但非真实运行证据 | 全部标注待执行，不虚构测试日志、GitHub截图或CCB签字 |

## 仍需全组做出决议
- **D01（重要）**：逾期图书已归还且没有其他欠还时，是立刻恢复 NORMAL，还是继续 RESTRICTED？最新 SRS 的无空格文件已将 AC-7 改为 NORMAL，但同目录带空格的旧版仍写 RESTRICTED。当前参考实现：RESTRICTED解除，**FROZEN持续到管理员解冻**（旧库没有人工冻结标记）。
- **D02**：正式确认不收费、不计算罚金，与原课程分工中罚金测试样例不一致。
- **D03**：已有证号 `1001` 长度4位，SRS要求6-12位；当前临时兼容4-12位。
- **D04**：R003最新变更分析已明确最多1次、一次延长15天；当前数据库变更台账没有实施日期/验收结果，尚不可称为交付完成。
- **D05**：真实库缺少活动借阅唯一索引、密码列遗留命名；涉及迁移必须先备份和审批。

## 安全限制
本套是本机/实验室课程演示项目，不是可直接暴露公网的图书馆生产系统。当前没有账户锁定策略、持久化管理员用户表、审计合规体系、HTTPS反向代理配置等生产要素。原上传连接指南中出现的真实密码不会出现在任何最终文件里；如果此前已经共享，建议负责人自行轮换。
