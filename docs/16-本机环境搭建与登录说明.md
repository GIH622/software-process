# 本机环境搭建与登录说明

> 面向新接手本项目的成员。按本文从零配到"能登录、能查数据"，约 10 分钟。
> **本文不记录任何真实口令**，口令由使用者自己设定并只存在于本机运行配置中。

## 一、前置条件

| 组件 | 要求 | 说明 |
|---|---|---|
| JDK | 17 或 21 | **不要用 JDK 24**，会让 Mockito 无法 self-attach，全部测试报错；JDK 21 实测可用 |
| Maven | 3.9+ | 可不安装：IntelliJ IDEA 自带 Maven（本文以 IDEA 内置 3.9.11 为例） |
| MySQL | 8.0+ | 本文以 MySQL 8.4.4 实测 |
| IDE | IntelliJ IDEA | 运行 Spring Boot 用 |

检查：

```powershell
java -version
# IDEA 内置 Maven 的路径示例
& "D:\IDEA\IntelliJ IDEA 2025.3.4\plugins\maven\lib\maven3\bin\mvn.cmd" -v
```

## 二、创建数据库与应用账号

**这一步是 500 错误最常见的根因**：代码里 `DB_USERNAME` 默认是 `library_app`、`DB_PASSWORD` 默认为空，如果库和账号没建过，任何业务接口都会报 `Access denied for user 'library_app'@'localhost'`。

用 root 执行（口令自己填）：

```sql
CREATE DATABASE IF NOT EXISTS library_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER IF NOT EXISTS 'library_app'@'localhost'  IDENTIFIED BY '<本机口令>';
CREATE USER IF NOT EXISTS 'library_app'@'127.0.0.1' IDENTIFIED BY '<本机口令>';
GRANT ALL PRIVILEGES ON library_dev.* TO 'library_app'@'localhost';
GRANT ALL PRIVILEGES ON library_dev.* TO 'library_app'@'127.0.0.1';
FLUSH PRIVILEGES;
```

## 三、建表（顺序不可颠倒）

在项目的 `sql` 目录下执行（MySQL 客户端对中文绝对路径的 `SOURCE` 会失败，必须先进入目录）：

```powershell
$env:MYSQL_PWD='<本机口令>'
mysql -u library_app --host=127.0.0.1 --port=3306 --default-character-set=utf8mb4 `
  --database=library_dev --execute="SOURCE library_init.sql; SOURCE requirement_change_log.sql;"
```

期望 5 张表：`reader_account`、`book_inventory`、`borrow_record`、`operation_log`、`requirement_change_log`。

**若要用 R003 续借**（默认关闭），需额外执行一次迁移，给 `borrow_record` 加 `renew_count` 列：

```powershell
SOURCE 20_CR001_renewal_optional.sql;
```

> 不要执行 `sql/library_db.sql`：那是旧库快照，含 `DROP TABLE`，已退役并从仓库移除。

## 四、配置运行参数

`Run → Edit Configurations → LibraryApplication → Environment variables`，填入下列变量（口令自己定）：

```
DB_URL=jdbc:mysql://127.0.0.1:3306/library_dev?serverTimezone=Asia%2FShanghai&useUnicode=true&characterEncoding=utf8&useSSL=false&allowPublicKeyRetrieval=true
DB_USERNAME=library_app
DB_PASSWORD=<本机口令>
LIBRARY_ADMIN_ACCOUNT=admin
LIBRARY_ADMIN_PASSWORD=<自定管理员口令>
LIBRARY_DEMO_READER_PASSWORD=<自定读者口令，至少 8 位>
SPRING_PROFILES_ACTIVE=demo
LIBRARY_RENEWAL_ENABLED=false        # 需要测 R003 时改 true
```

要点：

- `admin-password` 为空时**管理员永远登录失败**（`AuthController` 里有 `!config.adminPassword.isBlank()` 判断），必须设一个。
- `SPRING_PROFILES_ACTIVE=demo` 会自动初始化演示读者 1001~1010 与 4 本样例图书；该 profile 会校验当前库名必须是 `library_dev`，避免污染其他库。
- 这些变量只存在于 IDEA 的 `.idea/workspace.xml`，该目录已被 gitignore，**不会进 Git**。

## 五、启动与验证

```powershell
# 方式一：IDEA 直接 Run LibraryApplication
# 方式二：命令行
mvn -B -DskipTests package
java -jar target\library-process-dev-1.0.0-SNAPSHOT.jar
```

验证顺序：

```powershell
# 1) 存活探针（不查库，只能证明 HTTP 起来了）
curl http://127.0.0.1:8080/api/health

# 2) 管理员登录（不查库，证明口令配置生效）
curl -X POST http://127.0.0.1:8080/api/auth/login -H "Content-Type: application/json" `
     -d '{"account":"admin","password":"<自定管理员口令>"}'

# 3) 查数据（真正验证数据库）
#    用第 2 步返回的 csrfToken 建会话后 GET /api/books
```

## 六、常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录成功但所有页面 500「服务器处理失败」 | 数据库连不上 | 看 `logs/library.log` 里的 `SQLException`；对照本文第二、三节补齐库、账号、表 |
| `Access denied for user 'library_app'@'localhost' (using password: NO)` | 未配置 `DB_PASSWORD`，或账号不存在 | 配 `DB_PASSWORD`；确认账号已创建 |
| `ERROR 1524 (HY000): Plugin 'mysql_native_password' is not loaded` | MySQL 8.4 默认不加载该插件，旧账号仍用它 | `ALTER USER ... IDENTIFIED WITH caching_sha2_password BY '<口令>';` |
| 管理员登录始终 401 | `LIBRARY_ADMIN_PASSWORD` 为空 | 必须设非空值 |
| 测试全部报 `Could not initialize plugin: MockMaker` | 用了 JDK 24 | 换 JDK 17 或 21 |
| `mvn spring-boot:run` 报 `ClassNotFoundException` | 中文路径下 forked classpath 解析异常 | 改用 `mvn -DskipTests package` + `java -jar` |

## 七、跑自动化测试（不需要 MySQL）

```powershell
$env:JAVA_HOME='D:\java'      # JDK 17 或 21
mvn -B test
```

测试用 H2 内存库与 `application-test.yml` 中的固定虚拟口令，**不接触真实数据库、不需要任何真实口令**。期望结果见 `docs/evidence/junit-local-jdk21-20261023/执行记录.md`（51 个测试全部通过）。
