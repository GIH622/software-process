## 一、为什么用独立实例而不是本机 3306

本机 3306 的 MySQL 是 8.4.4，其中 `library_app` 账号仍使用 `mysql_native_password` 插件，而该插件在 MySQL 8.4 中**默认不再加载**，导致客户端报：

```
ERROR 1524 (HY000): Plugin 'mysql_native_password' is not loaded
```

root 口令未知，直接改账号有风险。因此另起一个**隔离实例**（独立数据目录 `D:\mysql_qa_data`、端口 3308），对既有环境和队友数据零影响。

## 二、可复现的准备步骤

```powershell
# 1. 初始化隔离数据目录（root 空口令）
mysqld --initialize-insecure --basedir=C:\mysql-8.4.4-winx64 --datadir=D:\mysql_qa_data
# 2. 启动
mysqld --basedir=C:\mysql-8.4.4-winx64 --datadir=D:\mysql_qa_data --port=3308 --console
# 3. 建库建账号
mysql -u root --port=3308 -e "CREATE DATABASE library_dev CHARACTER SET utf8mb4;
  CREATE USER 'library_app'@'127.0.0.1' IDENTIFIED BY '<本机口令>';
  GRANT ALL PRIVILEGES ON library_dev.* TO 'library_app'@'127.0.0.1'; FLUSH PRIVILEGES;"
# 4. 建表（在 sql 目录下，顺序不可颠倒）
SOURCE library_init.sql; SOURCE requirement_change_log.sql;
# 5. R003 受控迁移
SOURCE 20_CR001_renewal_optional.sql;
# 6. 构建并启动（demo profile 初始化 10 位演示读者与 4 本样例图书）
mvn -B -DskipTests package
java -jar target\library-process-dev-1.0.0-SNAPSHOT.jar
```
